# 非零像素 P99：12 个固定区域比较

2026-10-20。完成 12 个 case、29,535 个固定 CP_B 实例、458 个 case×蛋白测量通道的比较。非零像素 P99 使 51 个原本分母为零但仍有信号的通道可以计算；另 1 个全零通道保持为零。**数值缺口得到解决，但本轮不能证明非零信号都可信，也不足以确认统一生产方案。**

## 比较设计

- 固定原 12 个来源、ROI、Z 层和 CP_B mask，不重新分割。大图使用此前冻结的 ROI，不将区域统计称为整片统计。
- 对照：`clip(x / P99(x), 0, 1)`；候选：`clip(x / P99(x[x > 0]), 0, 1)`。两者均不扣 P1、不加 log/arcsinh、滤波或其他缩放。分位数使用精确 linear 插值。
- `x` 是来源发布文件在本轮归一化前的像素，可能已被来源处理，不等同于仪器原始计数。全零通道直接保存零；对照分母为零且仍有信号时保存 NaN，不发明替代分母。
- 每细胞逐通道取 mask 内全部像素的均值，包含零像素。非零条件仅用于估计分母，不用于筛选细胞内求均值的像素；背景 label 0 不建行。
- 恢复此前因多靶标/蛋白家族排除的 28 个测量通道，包括 panCK、CK8/18、HLA 组合、Collagen、S100 等；两种方法使用完全相同的 458 个通道。保留来源身份，不将一个组合测量拆成多个独立蛋白强度；完整 protein-bank 映射仍未完成。
- 本轮两个候选均去掉 P1，因此结果不是“旧 P1/P99 与非零 P99”的单因素比较。P99.8 只记录为统计量，没有执行第三套表达方案。

对每个 case 查看选定通道的整个 ROI 概览，没有逐细胞裁剪审查。选图规则固定：此前未定义非空通道中最稀疏与最不稀疏的各一个，再取一个恢复纳入的测量通道，空位由常见 marker 补齐，最多三个。全部通道均作数值统计。

图件第一列为来源像素的 `log1p / log1p(max)`，仅供观察，未用于定量；其余三列使用固定 0–1 色标。预览按标注作最大值池化以显示稀疏点，不能据缩略图估计原生信号面积。计算均使用原生像素。

孤立比例仅描述八邻域空间形态，不是噪声率；成簇结构也不保证抗体特异性。Mask 外可能存在真实膜、基质信号或漏分割细胞，不能把 mask 内外均值比解释为真实信噪比。没有阴性对照或人工信号真值，本轮只能判断结构是否保留，不能完成生物学信号/背景分类。

## 解释与建议

1. **可计算性改善明确。** 非空、非负通道的正像素 P99 大于零，避免被大量零值压成零分母；也不会因额外补入零背景而改变分母。
2. **两种方法均有定义时，候选不会普遍抬高强度。** 非零 P99 不小于全像素 P99，故候选像素强度不大于对照。MIBI 三个 case 的均值比例中位数为 0.380–0.585；Ly COMET 与 Nirmal CyCIF 的来源像素全为正，两种方法基本相同。变化由输入稀疏性决定，不能把这 12 个 ROI 的规律推广为平台定律。
3. **变暗本身不证明变差。** 406 个两者均可计算的非空通道，细胞表达 Spearman 中位数为 0.99994，最低约 0.953，排序大多保留。缩放降低饱和也可能保留更好的强弱差别，但该相关性不证明生物学有效性或训练收益。
4. **非零不等于有效信号。** 来源的去背景、阈值、量化方式会改变正像素集合；全为正的背景不会被排除，极稀疏的噪声也可被缩放至较亮值。这条规则没有新增信号判别或降噪能力。

建议保留本轮结果作为候选证据，不以“没有 NaN”确认统一生产规则，也不因 P99 退化删除整个 marker。尚待讨论的是如何界定可用于尺度估计的信号与背景、是否需要跨图可比的尺度；本轮未自动加阈值或选择下一套方法。

- 12 个 case 的实例标签、cell_index、行数与原 CP_B 定量结果一致；候选矩阵全部有限且在 [0,1]，所有矩阵 Parquet 重读一致。
