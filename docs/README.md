# CellWeft 文档入口

当前项目处于架构搭建阶段。入口按职责组织；尚未建立的专项规范继续以研究计划中的对应章节为准。

| 职责 | 唯一维护位置 |
| --- | --- |
| 科学目标、范围与里程碑 | [研究计划](project/research_plan.md) |
| 已验证进度、阻塞与下一步 | [当前状态](project/status.md) |
| 已接受决定与依据 | [决策记录](project/decisions.md) |
| 模块与接口归属 | [架构概览](architecture/overview.md) |
| SSD/NAS 路径与产物归属 | [存储规范](architecture/storage.md) |
| 协作、提交与发布流程 | [开发流程](development/workflow.md) |
| 文献与外部资源 | [参考索引](references.md) |
| 历史初始化规格 | [归档说明](archive/README.md) |

后续数据接入记录归 `data/`，评价协议归 `evaluation/`，实验设计和结果摘要归 `experiments/`，未决讨论归 `project/discussions/`。当前目录清单由 `../configs/layout.json` 维护。

现行要求在所属规范中维护，决策记录解释原因，实验记录描述实际执行。历史文档保留当时含义；不因后续实现而改写为已批准或已验证的证据。README 提供导航，不重复维护完整参数和实验状态。
