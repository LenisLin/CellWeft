**图版设计。** 下文为拟采用的分析协议。实施流程及当前进度见[临床实施工作流](../development/clinical_figure4_5_workflow.md)和[当前状态](../project/status.md)。

## 1. 科学问题与 Figure 4 的衔接

核心问题：对于不同结构或细胞状态的 NR 相关区域，改变哪些成分、改变多少，能够使局部表征接近匹配的真实 R 相关参考？沿路径累积这些编辑时，患者级预测响应概率 \(p_R\) 是否升高？

总体路径：Figure 4 临床相关区域 → 操作定义与典型案例核验 → NR 区域聚类、代表区域与归因 → 归因指导的单一及组合编辑 → 局部 patch/cell 方向与真实 retrieval → 局部效果的患者级汇总及逐区域累积编辑下的患者级响应概率曲线。

Figure 4 提供治疗前 patch 表征、坐标、折外 MIL attention、有方向的区域贡献、细胞标签、实测 marker 和空间关系；其患者分组、TRG 定义及读出沿用[Figure 4 协议](figure4_gastric_cancer.md)。Figure 5 在开发队列 D 开展；每位患者使用未以该患者任何 panel、时间点、ROI 或 crop 训练的对应折外模型，并在全部编辑节点固定该模型及读出。独立队列 V 不用于编辑策略选择或调参，继续承担 Figure 4 的锁定临床预测。

主分析使用治疗前组织及治疗前真实参考。治疗前后组织可为方向解释提供补充，须考虑胃镜与手术取样差异及多种治疗作用。NR/R 是来源患者的临床分组；局部区域称为 NR/R 相关区域，其局部状态由测量和结构分析支持。

输入编辑后的表示移动用于提出候选微环境改造假设。Figure 4 观察结果、距离和检索共享表征与临床信息，证据关系须如实说明；患者级结果报告预测响应概率变化，不解释为治疗疗效变化。

统一语法：真实区域为背景，匹配的 R 参考显示轮廓；原始区域为大点。不同单一操作从原始点分叉，递增剂量连接为路径，组合操作由对应单一操作终点继续连接。每个终点标注操作、剂量、到该目标参考的距离及距离改善。

操作颜色、线型、节点编号与右侧检索对象一致；原始区域也保留 retrieval。主图每条路径显示排序第一的真实对象，完整 Top-k、其他代表及对照放补充。组织图保留物理比例尺、统一通道和显示范围；编辑输入图与检索到的真实图分别标注。

## 3. 分析单位与固定读出

结构分析单位为具有足够物理视野的固定组织窗口 q，内部包含多个模型空间 token。CellWeft 内部 patch 为 8×8 像素，每个 224×224 crop 对应 28×28 个空间 token；病理结构窗口与内部 token 分别记录，窗口物理尺寸依据逐图像素尺度确定。局部方向和分布使用空间 token；患者×时间点 MIL bag 将该患者该时间点全部合格图像的 crop CLS 平铺，每 crop 输入为 768 维 CLS。

\[
H_q^{(e)}=\{h_{q1}^{(e)},\ldots,h_{qn_q}^{(e)}\},\qquad
P_q^{(e)}=\sum_jw_{qj}\delta_{\widetilde h_{qj}^{(e)}},\qquad
z_q^{(e)}=\sum_jw_{qj}\widetilde h_{qj}^{(e)}.
\]

e=0 为原始输入；波浪号表示固定的特征处理，权重和为 1。P 用于分布距离，z 用于区域聚类、投影及候选检索。原始与编辑条件固定窗口、有效位置、coverage/ownership、特征处理和空间读出权重。

空间特征按[模型接口](../architecture/model.md)读取。比较完整区域与固定保留细胞；另读取直接操作 mask 之外的位置，区分输入直接改变和周围表示变化。编辑源为 edited image＋instance view；替换及 marker 数值编辑后，按原规则计算需要报告的受影响细胞 whole-cell 表达。删除移除目标实例区域，按既有 O=0 语义处理原实例像素。编辑沿对应 Figure 4 固定网格和原 bag，固定 baseline q995、坐标及读出位置，重新编码像素或实例读出成员受影响的全部 crop；范围由[编辑规范](../architecture/editing.md)维护。

## 4. 参考、检索与供体库

三类库分别记录用途：R 参考分布用于方向量化，混合真实区域／细胞库用于 retrieval，供体库用于构造替换或状态编辑输入。同一来源可承担不同用途，但实际成员和排除规则分别记录。

1. 依据 Figure 4 的固定规则选择临床相关区域，匹配治疗前时间点、组织区室、物理视野、有效覆盖和测量条件；按患者平衡采样或赋权。确认：每个库有选择规则、有效患者数及来源。
2. 用其他患者的 R 相关区域构建固定参考。优先选择与原始区域组织结构／区室相近的 R 参考亚型，在编辑前固定为该区域的目标；到整体 R 参考的距离可作补充。确认：每条路径有明确的匹配依据和目标参考，参考不随编辑终点变化。
3. Retrieval 库同时保留 R、NR 来源，按表征距离排序后标注临床信息。排除查询患者，涉及供体操作时另排除供体患者。确认：检索结果可追溯且没有来源患者泄漏。
4. 供体优先使用同 panel、测量条件可比的真实细胞，记录身份、状态、尺寸、形状及来源。确认：供体与查询成员分离，处理规则可复现。

D 内聚类、归因和策略筛选属于发现与探索。需检验锁定策略的患者泛化时，再设置患者留出；查询患者从参考／检索／供体库排除本身不构成独立的策略验证。

## 5. NR 区域聚类与归因

1. 从 Figure 4 中 NR 患者的治疗前组织，按固定规则选择与较低预测响应概率相关的区域，并保留相近区室参照。Attention 定位候选，有方向的贡献依据 Figure 4 读出。确认：区域可返回原图和原临床模型。
2. 对患者平衡后的区域向量建立 kNN 图，拟采用 Leiden 聚类；UMAP 用于展示。根据患者重采样稳定性、区室及批次分布确定分辨率。确认：每类报告区域数、患者数、中心／批次组成及稳定性。
3. 选择接近类中心的真实 medoid 作为主图代表；全部合格成员进入定量。确认：代表图对应真实区域，选择依据与编辑效果无关。
4. 结合实测 marker、细胞组成和空间关系归因，再制定该类操作。确认：类别名称有实际测量支持，未支持者保留描述性标签。

| 优先研究类型 | 归因依据 | 优先操作 |
| --- | --- | --- |
| T 细胞耗竭相关状态型 | T 细胞身份及多 marker 联合状态、同类状态参照 | 单个或少数几个指定 marker 的数值编辑 |
| CAF 界面型 | CAF 的肿瘤边界富集、T–tumor 间覆盖和界面组织 | 分级删除／减少、CAF→T 替换 |
| CAF–Mac 界面型 | CAF/Mac 共同界面分布及其与 T 细胞的位置关系 | 分别删除 CAF 或 Mac、联合删除；按归因选用 CAF→T 替换及少量组合 |

三类为优先生物学方向，实际聚类不强制为三簇；同一类型可包含多个簇。耗竭相关命名取决于 panel 联合证据，单个 PD-1 或 TOX 信号不足以确定功能耗竭。

## 6. 编辑操作与剂量

### 6.1 界面相关细胞的删除与减少

1. 识别肿瘤边界及附近 T 细胞，为 T 细胞到邻近肿瘤边界建立局部连接带。确认：物理宽度、边界及连接规则固定。
2. 按实例 mask 与连接带相交识别 CAF/Mac，根据覆盖连接带数量或界面占有程度排序。确认：选取可返回 stable cell IDs 和原图。
3. 建立低／中／高剂量嵌套删除集合；减少定义为删除较少目标细胞。确认：每档记录实际细胞数、面积和位置，剂量数值在数据盘点后锁定。
4. 按编辑规范同步删除并完整重新编码；设置数量、面积尽量匹配的非界面同类细胞删除及随机对照，记录残余不平衡。确认：目标移除，其他自身测量及固定读出保留。
5. CAF–Mac 类型分别执行删除 CAF、删除 Mac 和联合删除；比较时报告编辑规模。确认：保留单一和联合路径及全部方向结果。

原有 T 与肿瘤的坐标不因删除改变，其欧氏距离保持不变。直接改变的结构指标包括连接带内 CAF/Mac 覆盖和界面占有；距离、接触和检索结果按实际几何解释。

### 6.2 真实供体细胞替换

首版替换固定为 CAF→T：每次移出一个 CAF、置入一个真实供体 T 细胞，细胞数不净增加。

1. 从供体库选择指定亚型／状态、大小、形状及测量条件可比的真实 T 细胞，记录来源和选择规则。
2. 按[替换规则](../architecture/editing.md#61-细胞替换)更新图像、实例及关联，记录替换数、面积和几何变换。
3. 按[编辑规范§5](../architecture/editing.md#5-比较与保存)重编码受影响窗口，执行同状态替换对照。分别分析供体预置状态和原有保留细胞的响应。

供体已知像素及测量构成编辑输入；检索结果另从排除供体患者后的真实库取得。供体 T 亚型／状态、几何接受规则及替换邻域更新在实施前锁定。

### 6.3 T 细胞指定 marker 数值编辑

仅编辑单个或少数几个指定蛋白的 marker 数值，可比较不同蛋白组合和改动程度。优先用同一 T 细胞亚型的实测参考，为各指定蛋白定义目标水平或模板；保留位置、形状、身份 marker 和所有未选蛋白的原始输入。

使用空间模板时，按下式调整选定通道：

\[
I_m^{(\alpha)}(u)=(1-\alpha)I_m^{(0)}(u)+\alpha T_m(u).
\]

\(T_m\) 为经过几何对齐、测量尺度处理的指定 marker 实测模板，数值改动限定于目标实例及指定通道。按相同定量规则可从编辑后的实例像素计算编辑细胞值，用于记录；模板对齐、参考至目标的尺度处理及 \(\alpha\) 网格在实施前确定。

操作名称写明具体改动，例如降低指定 marker 信号，或将所选的几个 marker 分别向各自目标水平调整。Marker 观测删除用于检验对该观测的依赖；数值编辑用于检验指定输入改变。二者按不同操作记录。

被指定改变的 marker 是输入条件。是否对应药物阻断、功能恢复或耗竭逆转需相应实验依据。观测状态、原始测量与编辑来源按[数据合同](../architecture/data_contract.md#5-figure-5-编辑视图设计待实现)保留。

## 7. 距离、方向与二维路径

\[
d_R^{(0)}=D(P_q^{(0)},P_{\mathcal R}),\quad
d_R^{(e)}=D(P_q^{(e)},P_{\mathcal R}),\quad
\Delta d_R^{(e)}=d_R^{(0)}-d_R^{(e)}.
\]

\(P_{\mathcal R}\) 是按 §4 为该区域固定的匹配 R 参考分布。\(\Delta d_R^{(e)}>0\) 表示接近该目标；\(D(P_q^{(0)},P_q^{(e)})\) 表示变化幅度。到 NR 参考的距离也可作补充。只比较一个区域向量时使用向量距离；分布距离使用窗口内部 token 集合。

在固定的高维特征空间比较区域 token 分布，拟采用去偏 Sinkhorn 散度。若采用 GeomLoss `p=2`，运输代价为 \(\lVert x-y\rVert^2/2\)。实施前锁定归一化、患者／位置权重、采样、正则和求解设置。Methods 和图注使用实际计算量的名称。

仅使用真实区域拟合一次展示投影，编辑向量通过固定 UMAP transform 放入同一坐标；不因操作重拟合投影。二维箭头来自 z，标注的分布距离来自 P，箭头长度不承担高维距离的数值含义。

## 8. Patch 与 cell retrieval

### 8.1 Patch 检索

1. 使用区域向量进行近邻召回，再用区域内部表征分布距离重排。确认：候选规模、Top-k、距离和排除规则固定。
2. 原始区域及每个编辑节点分别检索，主图展示 Top-1；完整 Top-k 尽量覆盖不同患者。确认：排名与来源可回溯。
3. 同时显示最近邻绝对距离及其在真实区域检索距离中的位置。确认：能够识别仍远离真实组织库的编辑结果。
4. 用相同物理视野展示真实图像、细胞图及临床来源信息。确认：临床标签在排序后标注，R/NR 均可成为结果。

检索说明编辑表征接近的真实形态。距离和检索共享表征，二者作为相互解释的证据；实际干预后的组织图像需要独立观测。

### 8.2 Cell 方向与检索

| 编辑情形 | 主读出 | 对齐和解释 |
| --- | --- | --- |
| 删除周围 CAF/Mac，T 自身测量固定 | 保留 T 的 cell embedding | 对齐同一批保留 T IDs，以真实同类 T 细胞的邻域为方向参考 |
| 编辑 T 自身指定 marker | 目标 T 的 cell embedding | 以真实同类 T 细胞的指定蛋白状态为方向参考，分别记录指定输入改变与模型读出 |
| 替换进入新细胞 | 新进入细胞与原有保留细胞分别读取 | 供体预置状态与保留细胞背景变化分别展示 |

Cell embedding 从图像空间特征与实例 mask 读取，可能随同一 crop 内其他输入的编辑而变化；保留细胞的原始实测值仍按原始记录使用。物理关系另由原始坐标、实例和空间表征分析。

Cell retrieval 限定真实同类／同亚型细胞。邻域编辑时匹配自身状态，展示检索细胞及周围组织；marker 编辑时说明人为修改通道。单细胞检索使用向量距离，细胞集合方向可使用固定分布距离，二者分别标注。

## 9. 典型案例核验与分型探索

### 9.1 典型结构示例

1. 按固定规则选择 Figure 4 已有证据的 tumor–T–CAF/Mac 区域。确认：基线结构与归因证据可查。
2. 完成 no-op、目标界面删除、匹配非界面删除及所需替换／marker 示例。确认：既有删除规则及新操作的一致性要求满足。
3. 比较区域距离、mask 外变化、保留 T contextual 和真实检索。确认：同时保留符合假设、无明显变化和相反方向。
4. 将结果用于判断操作和读出的可用范围。确认：典型案例的流程核验与真实干预验证分别记录。

### 9.2 分型指导的策略探索

1. 对归因明确的每类 NR 区域固定少量机制相关候选、剂量和目标参考。确认：操作与归因相连。
2. 先枚举单一操作及剂量，再考察少量有依据的两步组合。确认：每个节点均保存距离、检索和实际成本。
3. 比较单一、组合及匹配对照，报告数量／面积和指定 marker 的改动程度。确认：较大改动不被直接解释为更有效机制，组合增益按匹配成本比较。
4. 对同一操作类别探索最低成本路径。删除以细胞数／面积、替换以次数、marker 编辑以改动数／程度记录；跨类别并列报告。确认：不使用未经定义的统一成本。
5. 若使用达到目标状态的阈值，依据其他真实 R 区域的患者留出距离校准并在查询编辑前固定。确认：搜索结果仅称满足既定模型参考标准的候选路径。

初版采用有限枚举与逐步评估；更长路径或复杂策略学习属于后续扩展。主图展示 medoid 路径，定量覆盖该类全部合格区域。

## 10. 表达证据、患者汇总与临床连接

实测证据比较原始区域、R 参考及 retrieval 真实区域的细胞比例／密度、同类 marker、CAF/Mac 界面占有和 T–tumor 关系。使用热图、dot plot 或空间图；人为改动 marker 与真实测量分开标注。保留细胞的原始表达不因重新编码自动改变。

Cell adapter 的蛋白读出与 Figure 2／3 的像素重建分别按模型规范读取；本图主分析使用真实测量、参考与检索解释，并标明人为修改的输入通道。

### 10.1 区域独立比较与患者级汇总

区域层独立比较每个区域的原始输入与其单一／组合编辑，5e 展示从该区域原始输入出发的局部多路径、到匹配 R 参考的距离及真实 retrieval。按患者汇总局部距离变化：

\[
\overline{\Delta d}_{R,i,e}=\operatorname{mean}_{q\in i}\Delta d_{R,q,e}.
\]

区域先汇总到患者，再比较操作；每位患者按固定规则贡献结果，报告患者数、区域数、效应量和患者级置信区间。随机对照先在区域内汇总，重采样以患者为单位并保留操作配对。类型×操作矩阵同时标明有效人数和缺失，不以区域或细胞数替代患者样本量。

### 10.2 患者级逐区域累积编辑与响应概率

R／NR 标签由患者原始 TRG 分组得到，预测单位为患者。临床曲线采用 Figure 4 固定折外二分类头的 R 类概率 \(p_R\)。记未编辑基线概率为 \(p_0\)，第 \(k\) 步累积编辑后的概率为 \(p_k\)：

\[
G_k=p_k-p_0,\qquad g_k=p_k-p_{k-1}.
\]

\(G_k\) 为相对基线的累计 R 类概率变化，\(g_k\) 为单步概率变化；正值仅表示模型给出的 R 类概率上升，不表示实际治疗疗效改善。

1. 为患者内的每条累积路径指定编辑区域、各区域操作及加入顺序。用该患者的 Figure 4 折外 MIL 在原始治疗前完整 bag 上取得 \(p_0\)。
2. 第 \(k\) 步加入一个区域的指定编辑并保留前序编辑。以累积 edited image 和 instance view 重编码受影响窗口，更新完整固定位置 bag 的对应 CLS 行，其余行保留基线 CLS。需要报告的受影响细胞按原定量规则重算。重编码范围见[编辑规范§5](../architecture/editing.md#5-比较与保存)。
3. 固定预处理、模型参数、任务头及 bag 规则，在 \(H_i^{(k)}\) 上重跑同一患者的 Figure 4 折外 MIL，包括 pooling 和 attention，得到 \(p_k\)。
4. 每步记录本步区域在累积输入上的 embedding 方向、到匹配 R 参考的距离变化、真实 retrieval，以及患者的 \(p_k\)、\(G_k\) 和 \(g_k\)。用步骤号关联该区域的局部路径节点及检索结果。

5f 的曲线从 \(p_0\) 开始，横轴为累计编辑区域数或面积，纵轴为 R 类概率 \(p_R\)，并报告相对基线的概率变化。局部距离方向与患者级概率方向分别报告，允许不一致。新增 patch R/NR 分类器及随访编辑读出按额外问题另行论证。
