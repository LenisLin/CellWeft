# 输入编辑响应评价

评价 marker、细胞及 niche 输入编辑后，保留细胞与微环境的模型响应。输入操作与比较接口见[编辑规范](../architecture/editing.md)。

## 1. 读出

按固定对象和位置比较细胞、patch、crop 与区域表征。分别报告完整区域与固定保留细胞集合的变化。读出接口见[编辑规范§5](../architecture/editing.md#5-比较与保存)。

评价响应幅度、参考状态方向、空间背景依赖和组合效应。状态方向需要独立参考或经验证的读出。Marker 观测删除的解释限于输入编辑响应。

## 2. 对照与复现

1. 使用同一个 checkpoint，先执行 no-op 核对比较流程，再分析选定 cell/cell-type 或既有 niche 成员的同步遮挡。
2. 围绕具体状态假设设置删除数量、面积和位置等匹配的输入对照，比较固定保留细胞及固定区域；对照随机采样种子随实验记录。
3. 在 held-out 患者/cohorts 汇总状态评分和表示变化，记录预先固定的 probe/参考、实例 mask 范围、观测标记及 selection／ownership 规则。
4. 按[编辑规范§5](../architecture/editing.md#5-比较与保存)对齐并比较直接操作位置与周围区域。

## 3. 解释与验证

工程测试检验信息流与一致性；研究评价检验变化分布、选择性和跨 cohort 复现。不能以所有 embedding 变化越大越好作为验收标准。
用独立生物学证据评价响应解释；自然邻域差异提供支持，真实干预实验可进一步检验干预预测。未验证方向或组合效应仍记为待检验假设。
每个具体实验在 docs/experiments/ 中记录问题、成员、对照、读出、判断依据和结果入口；实际 cell IDs、数组、图件与日志写入 NAS。

## 4. Figure 5 应用与协议归属

胃癌区域的 NR 分型、候选操作、固定 R 参考、真实检索和患者累积响应读出见[Figure 5 协议](../paper/figure5_spatial_editing.md)。分别报告策略筛选、患者留出复核与真实干预验证，标明指定输入改变、实测表达和模型读出。

## 5. 外部扰动来源的响应解释

GSE278572 的逐细胞 ADT 计数支持按来源内对照估计细胞类型响应。GSE330295 的响应来自技术协变量回归后的 deviance residual，按批次 z-score。PRJDB16517 提供作者聚合的响应分数。测量定义见[蛋白扰动数据指南](../development/protein_perturbation_download_guide.md)，交付和准入见[当前状态](../project/status.md)。

来源内对照支持对特定条件、marker 和细胞类型的变化方向作解释。空间图像上的编辑模板和剂量需要单独确定跨尺度映射。该扩展作为独立 Figure 6 或补充材料候选。
